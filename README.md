## Release tags

Tags before 0.1.21 (0.1.17 – 0.1.20) are **reconstructed** from archived source
folders of the original builds; they are not the original development commits.

Tags `v0.1.17` to `v0.1.20` live on the `reconstructed-releases` branch: one commit per
version, built from archived source folders. No installer script (`.iss`) was archived for
0.1.17–0.1.19. Tag `v0.1.21` is on `main`.
